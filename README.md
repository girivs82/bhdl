# BHDL: Board Hardware Description Language

This repository contains the tooling, specifications, and examples for BHDL.

- **`/bhdl-*`**: Rust crates for the BHDL toolchain (parser, analyzer, CLI, LSP, etc.).
- **`/docs/spec`**: The BHDL language specification.
- **`/docs/examples`**: Example BHDL files.
